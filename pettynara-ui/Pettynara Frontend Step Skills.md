# Pettynara Frontend Step Skills

Bu file Pettynara frontend/home page ishlarini step-by-step qilish uchun yozildi.
Har bir skill alohida bajariladi. Bir skill tugagandan keyin build/test tekshiriladi, keyin keyingisiga o‘tiladi.

Umumiy design reference:

- Attached Pettynara preview style asos qilib olinsin.
- Soft bright hero background, real dog/cat image, cute Korean emoticon/cartoon decorations.
- Mint green primary, coral accent, warm cream background.
- Premium, cheerful, Korean-friendly pet marketplace ko‘rinishi.
- Community va Safety page/link qo‘shilmasin.
- Right sidebar/promo cards qo‘shilmasin.

Final homepage section order:

1. Navbar
2. Hero + normal search + Smart Search
3. Animal/Accessories category row
4. Pet Helpers
5. Popular Pets
6. Accessories
7. Footer
